Facial expression recognition, running entirely in your browser — no server, no upload. Model · Paper · Code · pip install rmn

YuNet detects faces, then ResMaskingNet (143M parameters, int8-quantised to 132 MB) classifies each crop into the seven FER2013 emotions. The model downloads once and is cached by your browser. Preprocessing matches the rmn Python package.
